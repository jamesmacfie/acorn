You'll tell the browser extension where each task's app answers while it runs, such as a development
server on `localhost`, so a tab on that app knows which task it belongs to.

## The result

With a task's app running at `https://acme-5b0d7c39.localhost:5173`, a tab on it:

- Shows the task under **This page** in the extension's panel, with the state line **Acme app running**.
- Gets a small marker in the page's bottom-right corner with the task's branch and **running**. Its
  menu has **Show in side panel**, **Ask about an element**, and **Open in Acorn**.
- Opens the task's [browser panel](/docs/build-plugins/node/show-a-panel-in-the-browser-sidebar/), if
  your plugin has one.

## Before you start

Read [Write the Node half](/docs/build-plugins/node/write-the-node-half/). The code is from
[`examples/plugins/acme-browser`](https://github.com/jamesmacfie/acorn/tree/main/examples/plugins/acme-browser),
which treats a task's `web` run target as its app.

## Why the list stays on your side

The extension matches tabs against your list in the browser. No tab's address goes to the Node for it,
and the person still decides which sites the extension may read.

## Mistakes

- An address for an app that isn't answering. List an app only while it runs, and drop it as soon as it
  stops.
- A public address, such as `https://staging.acme.example`. Only loopback hosts are taken, so a list
  can't claim someone else's site.
- `https://app.localhost:443`, or a path such as `https://app.localhost/x`. Write the origin the way the
  browser reports it: no default port, and no path.
- Answering a task's own agent. The extension calls with the device's credential, so refuse a
  credential bound to one task.

`taskAddresses` is one route, not a list of addresses:

```json manifest-invalid title="Wrong: acorn-plugin.json"
{
  "node": "./node.js",
  "contributions": { "taskAddresses": ["https://acme.localhost:5173"] }
}
```

```json manifest title="Right: acorn-plugin.json"
{
  "node": "./node.js",
  "contributions": { "taskAddresses": "/v1/p/acme/task-addresses" }
}
```

## In the terminal

This is a browser extension feature.

## Limits

- One route per plugin, and up to 64 addresses in an answer, at most 64 KiB.
- An address for a task that isn't active is dropped. One bad entry refuses your whole answer, and
  the other plugins' addresses still show.
