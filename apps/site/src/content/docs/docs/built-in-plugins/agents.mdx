The Agents plugin runs Claude Code and Codex as managed agent sessions: each task's **Agent** pane, with
its transcript, request cards, and message box, and Agent Center, which lists every session across your
tasks. The [Agents](/docs/agents/agent-sessions/) section of these docs covers it in full. This page is
the plugin's summary.

## Set it up

<Steps>

1. Install Claude Code or Codex on the Node's machine, and sign in to it there.

2. Open a task. The **Agent** pane opens with **Start a managed coding session**, and a card for each
   harness. Click **Claude Code** or **Codex**.

   <Checkpoint>A session opens with its message box. A harness acorn can't find says so on its card, such as "codex is not available on PATH."</Checkpoint>

</Steps>

## Agent Center

Click **Agents** in the left rail, or run **Open Agents**. It lists sessions across your tasks with
their state, counts how many are working and how many need you, shows each harness's health, and
searches every transcript. Its archived filter has **Restore** for a session you archived on its own.

## From the command palette

The plugin's commands include a new session and starting Claude Code or Codex in
the terminal drawer. [Agent sessions](/docs/agents/agent-sessions/) lists the session menu's commands.

## For agents

Every session gets acorn's tools through acorn's MCP server, scoped to its task, and the task's context
with its first message. Other plugins add to what sessions see: custom agents, skills, tool hooks, and
cards in the transcript.

## Settings

**Settings** > **Agents** has four pages from this plugin: **Harnesses and defaults**, **Custom agents**,
**MCP**, and **Limits and cost** ([Settings: Agents](/docs/settings/agents/)).

## In the terminal

The terminal client draws the same Agent pane: the roster, the transcript, the message box, the queue,
and request cards. It draws the plugin's Settings pages too. **Attach**, **Export**, and **Continue in terminal** need the
desktop app.

## Limits

- Managed sessions run Claude Code and Codex, and harnesses other plugins add. Aider runs only in the
  terminal drawer.
- A session lives as long as its task. Archiving a task retires its sessions.
- acorn doesn't move a session to another account when one runs out of plan usage.
