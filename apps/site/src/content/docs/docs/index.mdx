A workspace for working with coding agents, one task at a time.

Open a task and acorn gives it a branch, a Git worktree, terminals, and agent sessions, with the diff
and the pull request in the panes beside them. Use it from the desktop app or from your terminal. It's
the same workspace either way.

## The model in one picture

<Snapshot id="hero" />

The picture is one task, **Retry failed webhooks**, open in the desktop app. Everything in acorn hangs
on four ideas:

- A **workspace** groups projects. **Fernwood** in the top-left corner is the workspace. You can also
  keep each project on its own, with no grouping.
- A **project** is a folder on your machine, usually a Git checkout. Here it's **billing-api**.
- A **task** is one piece of work on one project. It gets its own branch and its own Git worktree, so
  two tasks never share files. Its agent sessions and terminals run in that worktree.
- **Panes** are the views a task shows side by side: the Agent pane, Changes, Notes, the editor, and
  more. The picture shows the Changes pane with the task's diff.

Archiving a task stops what runs in it and removes its worktree, and keeps its branch, notes, and agent
history. [Concepts](/docs/start/concepts/) has the rest of the model.

## Four ways to use it

| Client | What it is |
| --- | --- |
| Desktop app | The app for macOS and Windows. |
| Terminal client | `acorn` with no arguments. The same panes, drawn in a terminal, anywhere Node.js runs. |
| Command line | `acorn` with a command, such as `acorn task list`, for scripts and other agents. |
| Browser extension | A side panel in Chrome and Firefox on macOS, for talking to an agent from a web page. |

All four talk to a **Node**, the process that holds your data and runs your agents. The desktop app
starts one on your machine. [Desktop and terminal](/docs/start/desktop-and-terminal/) covers the two
clients you'll use most.
