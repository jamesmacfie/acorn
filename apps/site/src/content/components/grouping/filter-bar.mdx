Use `FilterBar` for the search or filter row at the top of a list. Put an `Input`, `Select`, or `Picker` in it, then any filter actions. It adds no tab stop and owns no state.

## Mistakes

- Reading the field's `onInput` from a tree. Only `onChange`, the committed value, crosses, so filter on that.
