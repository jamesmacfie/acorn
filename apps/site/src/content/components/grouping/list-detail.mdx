Use `ListDetail` with a `ListColumn` and a `DetailColumn` as its children. Above 80 columns the terminal draws both side by side, and below 80 it puts the list over the detail.

<Specimen id="list-detail" />

A pane can also name the `list-detail` layout, and the host draws the split. Use the node for a list and detail inside one region. For more information, see [Layouts](/docs/components/layouts/).

## Mistakes

- Passing the list in the `list` prop. A prop can't hold a tree, so a tree passes a `ListColumn` child and sets `split`.
- Naming a pane `list-detail` and also drawing a `ListDetail` inside it. The layout already draws the two columns.
