Use `DocumentTabs` for open files or sessions the reader switches between. Each tab can mark unsaved changes, a run state, or a preview, and `onActivate` sends the id of the tab pressed.

## Mistakes

- Marking unsaved changes with an asterisk in the label. Set `dirty`, and both hosts draw a dot.
- Expecting a tree's tabs to close. `onClose` isn't one of the twelve events, so a tree can't hear a close.
