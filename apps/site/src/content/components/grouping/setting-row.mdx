Use `SettingRow` for one setting inside a `SettingsSection`. The label names the control, `savedAt` draws **Saved** for two seconds, and `error` draws the save error.

## Mistakes

- Holding a **Saved** timer in your tree. Set `savedAt` to the time it saved, and the row keeps the timer.
- Putting two controls in one row. The label names one control, and with two it names none.
