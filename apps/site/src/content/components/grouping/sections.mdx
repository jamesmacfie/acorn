`Sections` is the shape of the pull request pane: a header, folds beside it, and the main region. Each section draws through a `render` function, and a function can't cross from a tree, so a tree draws nothing with it. Shell code uses it.

## Mistakes

- Sending `Sections` from a tree. Its sections' `render` functions are dropped on the way, and the node fails.
