Use `Row` for each item in a list, inside a `ListColumn`. `meta` draws at the end, `selected` marks the current item, and `variant="stacked"` puts a second child on a second line.

## Mistakes

- Sending `collapsedIcon` while the row isn't collapsed. A row with it draws collapsed, so send it only while its column is.
- Hiding controls until hover. The terminal has no hover, so a row's trailing controls always draw there.
