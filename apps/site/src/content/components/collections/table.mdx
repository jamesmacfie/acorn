Use `Table` with `TableRow`, `TableHead`, and `TableCell` children for data with the same fields per row. The terminal drops the lowest-priority columns first when it runs out of width, and says which it dropped.

## Mistakes

- Leaving out `priority` on wide tables. Mark the columns a reader can lose as `low`, or the terminal guesses.
