Put `RowActions` inside a `Row` for actions on that item. The desktop folds them behind one menu button. The terminal draws each action, because it has no hover to reveal them.

## Mistakes

- Expecting the desktop menu to list a tree's buttons. Its items are a function in shell code, so a tree's actions show in the terminal and the desktop draws only the button.
