Use `Graph` for steps and what they wait on, such as a workflow. Each card is in `nodes`, each join is in `edges`, and `positions` places them. The terminal draws the same cards as a list indented by rank.

## Mistakes

- Drawing a graph only a picture can explain. The terminal draws ranks and no wires, so the order has to make sense as a list.
