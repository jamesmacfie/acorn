Use `ModelPickerPopover` in a dialog or composer that generates text, so the reader can change the backend and model without the picker taking room. Put a `ModelBackendPicker` inside it, and pass `sparkle` for the ✦ trigger. `tipSub` is the tooltip's second line, such as the pick in force.

## Mistakes

- Drawing `ModelBackendPicker` straight into the dialog body. The app's AI dialogs keep it behind this button, at the start of the actions.
