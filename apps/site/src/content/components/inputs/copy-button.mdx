Use `CopyButton` beside a value the reader copies, such as a hash. The terminal copies with OSC 52 where it can, and prints the value to copy by hand where it can't.

## Mistakes

- Leaving out `always` in a tree. Without it the button shows only when the reader hovers its row, and a tree can't set the class that row needs.
