Use `Button` for an action. `variant` sets its weight, `tone` its meaning, and `onPress` is what the press sends. A `Button` with an `href` is a link that looks like a button.

## Related

## Mistakes

- Using `iconOnly` with an icon child. Use `IconButton`, which takes the icon name and a required label.
- Sending a prop as `undefined`. The host refuses the whole batch, so leave the prop out.
