`Menu` opens from a trigger, which is a function, and its items are a function too. Neither can cross from a tree, so a tree draws nothing with it. A plugin adds rows to acorn's own menus through its manifest, and a row's actions through `RowActions`.

## Mistakes

- Sending `Menu` from a tree. Its trigger is dropped, and the node fails. For more information, see [Add rows to context menus](/docs/build-plugins/ui/add-rows-to-context-menus/).
