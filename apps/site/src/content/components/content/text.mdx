Use `Text` for any run of words. `emphasis` says how it carries, such as `muted` or `strong`, and `tone` says what it means.

## Mistakes

- Leaving a bare string beside a heading. In the terminal a string outside `Text` overprints the line it sits on, so wrap it.
- Using `emphasis="mono"` to mean code in the terminal. A terminal is monospaced already, so it draws plain.
