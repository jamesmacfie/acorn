Use `CodeBlock` for a command, a snippet, or output the reader copies. Set `copy` to draw the copy control, and `ansi` for terminal output with color codes.

## Mistakes

- Relying on color in `ansi` output for the terminal. The terminal drops the escape codes and draws it plain.
