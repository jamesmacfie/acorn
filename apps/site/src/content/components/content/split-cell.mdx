`SplitCell` draws the old or the new half of a changed line in a split diff. The terminal has no split diff, because side by side needs 160 columns, and draws nothing for it.

## Related

## Mistakes

- Using split cells for a diff that must read in the terminal. Use `StackedDiff`, which is unified.
