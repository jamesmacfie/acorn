Use `UserAvatar` beside a person's name. It takes their `login` and, in `src`, the HTTPS address of the
picture their code host gives for them. Without `src` the desktop draws the login's initials, and the
terminal always draws them in brackets. A tree that passes a login and no `src` gets that login's
GitHub picture until the next plugin API major removes the fallback.
