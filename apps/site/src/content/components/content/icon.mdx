Use `Icon` for a shape that carries meaning, such as a check for passed. `name` is a Lucide name or a `brand:` mark, and `tone` colors it. For more information, see [Icons](/docs/components/icons/).

## Mistakes

- Using an icon the terminal has no mark for, with no word beside it. The terminal draws nothing for an unmapped name, so put the meaning in text too.
