Use `Kbd` for a shortcut in a line of text. The desktop draws a key cap, and the terminal writes the chord as its host does.

## Mistakes

- Spelling a chord for one platform, such as `Cmd+K`, in plain text. Put it in `Kbd`, and the host writes it its own way.
