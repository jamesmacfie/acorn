Use `Link` for text that opens a web page or acts. An `href` must be an HTTPS address, and the host opens it. For a place inside acorn, send `onPress` and ask the host.

## Mistakes

- Passing an `http:` or a relative `href`. The host drops any `href` that isn't HTTPS.
- Putting the explanation in `tip`. The terminal has no hover and draws nothing for it.
