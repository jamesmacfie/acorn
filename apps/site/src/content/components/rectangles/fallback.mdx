Put a `Fallback` inside a node a host can't draw, such as a `Rectangle` in the terminal. `forNode` names that node, and the host draws the fallback where the support table says it can't draw the node.

## Mistakes

- Using a fallback where the node draws. It draws only where the support table says the host can't draw the node it sits in.
