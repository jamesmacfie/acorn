A Node stat is a number on a Node's card on Fleet home, with your label beside it. acorn reads it from
your route on that Node. Give the label in singular and plural, so one reads "1 card stuck", not "1 cards
stuck".

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "nodeStats": [
      {
        "id": "stuck",
        "label": [
          "card stuck",
          "cards stuck"
        ],
        "data": "/v1/p/acme/stats/stuck"
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "nodeStats": [
      {
        "id": "stuck",
        "order": 100,
        "label": [
          "card stuck",
          "cards stuck"
        ],
        "data": "/v1/p/acme/stats/stuck",
        "refresh": 600
      }
    ]
  }
}
```
