A ref resolver labels your items wherever acorn shows their identifiers, such as a task's links,
without that surface knowing your plugin. acorn POSTs a batch of identifiers to your route and draws the
labels it answers.

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "refResolvers": [
      {
        "id": "issues",
        "kind": "issue",
        "resolve": "/v1/p/acme/refs/resolve"
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "refResolvers": [
      {
        "id": "issues",
        "kind": "issue",
        "resolve": "/v1/p/acme/refs/issues"
      },
      {
        "id": "projects",
        "kind": "project",
        "resolve": "/v1/p/acme/refs/projects"
      }
    ]
  }
}
```
