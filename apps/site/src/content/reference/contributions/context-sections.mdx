A context section adds your plugin's part to a task's context: what an agent reads about the task
when it starts. Your route answers reference data and short text, and acorn holds it to the byte and
token budget you declare.

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "contextSections": [
      {
        "id": "issue",
        "label": "Acme issue",
        "order": 300,
        "read": "/v1/p/acme/context",
        "maxBytes": 8192,
        "maxTokens": 2048
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "contextSections": [
      {
        "id": "issue",
        "label": "Acme issue",
        "order": 300,
        "read": "/v1/p/acme/context",
        "defaultIncluded": true,
        "timeoutMs": 3000,
        "maxBytes": 8192,
        "maxTokens": 2048
      }
    ]
  }
}
```
