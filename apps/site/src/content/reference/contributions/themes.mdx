A theme is a set of colors for acorn's palette tokens. You write the values, acorn checks each one and
generates the CSS, and the theme appears in **Settings > Appearance** beside the built-in ones, with your
plugin's name. You write no CSS, and none of yours reaches the window.

`tokens` must list every palette token, and no others. The fields table below names them all.

## A minimal example

```json manifest
{
  "contributions": {
    "themes": [
      {
        "id": "ember",
        "label": "Ember",
        "dark": true,
        "tokens": {
          "--bg": "#1e1f29",
          "--bg-subtle": "#252734",
          "--bg-hover": "#2d3040",
          "--bg-selected": "#363a4f",
          "--border": "#3a3d4f",
          "--border-strong": "#4b4f66",
          "--text": "#e6e7ee",
          "--text-muted": "#a9abbd",
          "--text-faint": "#7d8096",
          "--accent": "#f0883e",
          "--focus": "#f0883e",
          "--add-bg": "rgba(63, 185, 80, 0.15)",
          "--add-marker": "#3fb950",
          "--del-bg": "rgba(248, 81, 73, 0.15)",
          "--del-marker": "#f85149",
          "--add-word-bg": "rgba(63, 185, 80, 0.35)",
          "--del-word-bg": "rgba(248, 81, 73, 0.35)",
          "--hunk-bg": "#252734",
          "--hunk-text": "#a9abbd",
          "--warn": "#d29922",
          "--badge-border": "#4b4f66",
          "--shadow-popover": "rgba(0, 0, 0, 0.5)"
        }
      }
    ]
  }
}
```

## In the terminal

The terminal client uses the terminal's own palette, or a built-in theme's colors on a truecolor
terminal. A plugin theme doesn't change it.

## Mistakes

- Don't set `--is-dark` or `--color-scheme`. They come from `dark`.
- Named colors, `var()`, and nested color functions are refused. Write `#1e1e2e` or `oklch(0.7 0.15 250)`.
