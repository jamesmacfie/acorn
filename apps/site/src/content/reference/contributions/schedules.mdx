A schedule is work the Node runs for your plugin on a cadence, whether or not a client is open. The
Node POSTs to your route each time. The person sees each schedule in the trust prompt and in
**Settings > Schedules**, where they can pause it or change how often it runs.

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "schedules": [
      {
        "id": "sync",
        "name": "Sync Acme",
        "run": "/v1/p/acme/sync",
        "cadence": {
          "every": 3600
        }
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "schedules": [
      {
        "id": "sync",
        "name": "Sync Acme",
        "run": "/v1/p/acme/sync",
        "cadence": {
          "every": 900
        },
        "timeout": 120
      },
      {
        "id": "digest",
        "name": "Weekly digest",
        "run": "/v1/p/acme/digest",
        "cadence": {
          "weekly": {
            "day": 1,
            "at": "09:00"
          }
        }
      }
    ]
  }
}
```

## In the terminal

Schedules run on the Node, so it doesn't matter which client is open, or whether one is.

## Mistakes

- `timeout` is in seconds, not milliseconds.
- A plugin's schedule runs at most every 300 seconds, so `{ "every": 60 }` runs every 300.
