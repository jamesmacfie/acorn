A discovery lists data sources that depend on the account or project, such as one source per board.
acorn asks your route when someone browses sources, and each source it finds is available only in the
scope that found it.

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "dataSourceDiscoveries": [
      {
        "discoveryId": "boards",
        "handler": "/v1/p/acme/sources/discover"
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "dataSourceDiscoveries": [
      {
        "discoveryId": "boards",
        "handler": "/v1/p/acme/sources/discover",
        "providerId": "acme"
      }
    ]
  }
}
```
