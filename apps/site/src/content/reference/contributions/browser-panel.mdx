`browserPanel` adds a read-only panel to the browser extension's sidebar for a task, such as a local
stack's status and logs. Your route answers a view made of fixed blocks, and the extension draws them as
text, so none of your code runs in the browser. One per plugin.

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "browserPanel": {
      "label": "Stack",
      "route": "/v1/p/acme/browser-panel"
    }
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "client": "./client.js",
  "contributions": {
    "frames": [
      {
        "target": "pane",
        "id": "stack",
        "label": "Stack",
        "layout": "single",
        "regions": {
          "body": {
            "kind": "remote",
            "entry": "stack"
          }
        }
      }
    ],
    "browserPanel": {
      "label": "Stack",
      "glyph": "server",
      "pane": "stack",
      "route": "/v1/p/acme/browser-panel"
    }
  }
}
```

## In the terminal

This is a browser extension feature, not a client one.

## Mistakes

- Answer 404 for a task with no panel.
- A block kind or field the extension doesn't know refuses the whole view.
