A custom agent is a saved way to start a session: a harness, the options it starts with, instructions
for its system prompt, and the most it may do with acorn's own tools. It's data, so it needs no
permission. The trust prompt shows the instructions in full, and a version that changes them asks again.

## A minimal example

```json manifest
{
  "contributions": {
    "customAgents": [
      {
        "id": "reviewer",
        "name": "Reviewer",
        "harness": "claude"
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "contributions": {
    "customAgents": [
      {
        "id": "reviewer",
        "name": "Reviewer",
        "glyph": "eye",
        "description": "Reviews a diff and doesn't change files.",
        "harness": "claude",
        "options": {
          "model": "opus"
        },
        "instructions": "Review the task's diff. Report problems. Don't edit files.",
        "maxToolRisk": "read"
      }
    ]
  }
}
```
