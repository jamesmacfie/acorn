An agent context is an entry in the composer's list of things to attach to a message. The person
opens it, picks options your route lists, and acorn attaches the text your second route answers, stamped
with your plugin and the time.

## A minimal example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "agentContexts": [
      {
        "id": "issues",
        "label": "Acme issues",
        "options": "/v1/p/acme/context/options",
        "capture": "/v1/p/acme/context/capture"
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "node": "./node/index.js",
  "contributions": {
    "agentContexts": [
      {
        "id": "issues",
        "label": "Acme issues",
        "description": "Attach the issues linked to this task.",
        "options": "/v1/p/acme/context/options",
        "capture": "/v1/p/acme/context/capture"
      }
    ]
  }
}
```
