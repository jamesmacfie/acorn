A style pack changes acorn's shape rather than its colors: corner radius, borders, spacing, and
density. It's a partial set of style tokens. Any token you leave out keeps the default, and acorn checks
every value against what that token accepts.

## A minimal example

```json manifest
{
  "contributions": {
    "styles": [
      {
        "id": "rounded",
        "label": "Rounded",
        "tokens": {
          "--radius-surface": "var(--radius-lg)"
        }
      }
    ]
  }
}
```

## A fuller example

```json manifest
{
  "contributions": {
    "styles": [
      {
        "id": "rounded",
        "label": "Rounded",
        "description": "Larger corners and softer cards.",
        "tokens": {
          "--radius-surface": "var(--radius-lg)",
          "--elev-card": "var(--shadow-2)"
        }
      }
    ]
  }
}
```

## In the terminal

The terminal client draws no shapes, so a style pack changes nothing there.

## Mistakes

- One value acorn can't use refuses the whole pack.
- A pack can't change icons.
