# Chat proposal (not shipped)

The standalone workspace-chat proposal is not part of acorn. Current conversational work is the
task-scoped managed-agent system documented in [managed-agents.md](../../managed-agents.md) and
[features.md](../../features.md). There are no chat routes, chat tables, chat source, or chat
provider lifecycle described by this directory in the current product.

The remaining files are retained as design material only and must not be used as implementation
instructions or current API documentation.
