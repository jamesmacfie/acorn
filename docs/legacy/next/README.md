# Future work

This directory contains proposals and validation notes, not current runtime contracts. Shipped
behavior belongs in the parent [`docs/`](../) tree. A proposal becomes current only after its code,
tests, and parent topic documentation land together.

Current contracts are documented in:

- [architecture-overview.md](../architecture-overview.md)
- [api-reference.md](../api-reference.md)
- [plugins.md](../plugins.md)
- [authentication.md](../authentication.md)
- [security.md](../security.md)
- [state.md](../state.md)
- [testing.md](../testing.md)

The files here are intentionally not linked as implementation instructions. In particular, the
`chat/` directory describes an unshipped/superseded chat design, and must not be used as evidence that
chat routes, tables, or UI exist in the current product.
