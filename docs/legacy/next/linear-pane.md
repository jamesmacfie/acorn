# Linear pane follow-ups

The Linear source and task pane are shipped. Current provider behavior is documented in
[integrations.md](../integrations.md) and [features.md](../features.md); the route contract is in
[api-reference.md](../api-reference.md).

Possible follow-ups are UI improvements only: richer project filtering, better multi-connection
selection, and additional task-reference presentation. Any implementation must preserve connection-
qualified issue identity and the existing `/v2/p/linear` provider routes.
