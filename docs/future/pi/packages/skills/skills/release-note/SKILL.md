# Release note

1. Find what changed. Read the diff or the commits the person names. If they name nothing, use the
   uncommitted changes in the working tree.
2. Decide who notices the change. Write for that person, not for the developer who made it.
3. Write the entry in the format in [format.md](format.md). Follow it exactly, including its last line.
4. Show the entry in your reply. Don't write it to a file unless you're asked to.
