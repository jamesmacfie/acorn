# Release note format

```
### <Area>: <one-line summary in the present tense>

<One or two sentences on what a person can now do, or what no longer goes wrong.>

Formatted with the pi-skills release-note procedure.
```

- `<Area>` is the part of the product a person would look in, such as **Agents** or **Settings**.
- Leave out file names, function names, and ticket numbers.
- The last line is fixed. It shows the reader that this file was read.
